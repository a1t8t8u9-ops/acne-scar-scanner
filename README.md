# Acne Scar Scanner v0.5

スマートフォン向けPWA試作版です。v0.5では顔全体1枚の解析から、部位別セッション型へ変更しました。

## v0.5 workflow
1. セッション名と照明条件を設定
2. 額 → 右頬 → 左頬 → 鼻 の順に撮影
3. 各部位について正面光画像と斜光画像を登録
4. 斜光画像を中心に局所輝度差・エッジ・テクスチャを解析
5. 凹み候補を可視化
6. 候補数 / 面積率 / texture roughness / 平均候補サイズを保存
7. セッション全体をJSONとして書き出し

## Important limitation
現在は学習済みのニキビ跡専用AIではありません。斜光画像の局所陰影・エッジから凹み候補を抽出する画像処理プロトタイプです。髪、輪郭、照明ムラ、強い反射などで誤検出する可能性があります。

## Why region-guided capture?
顔全体1枚では鼻・口・マスク・髪などが誤検出源になります。部位を明示して近接撮影することで、解析対象を限定し、将来のscar-level segmentationや3D形状推定につなげます。
