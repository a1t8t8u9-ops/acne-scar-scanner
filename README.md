# Acne Scar Scanner v0.6

スマートフォン向けPWA試作版です。v0.6では、画像を入れた直後に解析せず、まず部位ROIを人間が確認・修正してから解析する流れへ変更しました。

## v0.6 workflow
1. 額 → 右頬 → 左頬 → 鼻 の部位を選択
2. 正面光 / 斜光画像をファイルまたはカメラから登録
3. 部位テンプレートに基づいてROIを仮置き
4. 上端 / 下端 / 左端 / 右端をタッチ操作で移動
5. ROIを確定
6. 斜光があれば斜光、なければ正面光を確定ROIで切り出す
7. 切り出したROIだけを簡易解析
8. ROI座標・結果を部位ごとに保存し、JSON書き出し

## Important limitation
現在のROI初期位置は部位テンプレートによる仮置きで、顔ランドマークによる完全自動推定ではありません。また正面光と斜光で構図が大きく異なる場合、同じ正規化ROIが同じ解剖学的位置を表さないことがあります。
