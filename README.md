# Acne Scar Scanner v0.4

スマートフォン向けPWA試作版です。v0.4では開発順序を変更し、Before/After比較より先に「写真1枚を解析する」機能を本体にしました。

## v0.4 pipeline
1. 写真を1枚読み込む
2. 顔が写っていればMediaPipeで顔検出
3. 頬ROIを自動または手動選択
4. 局所輝度差・エッジ・テクスチャを計算
5. 凹み候補を連結領域として抽出
6. 候補ごとの位置・大きさ・エッジ強度を算出
7. 画像形態から I / B / R の3タイプへ暫定分類

## Important limitation
現在の分類は臨床診断ではなく、単一RGB画像から得られる画像形態上の推定です。照明による影、毛穴、色調変化などを真の皮膚凹凸と完全には分離できません。
